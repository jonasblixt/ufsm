# v0 models

The models of uFSM v0.5.3 (the C/GTK editor's format), copied unchanged from the
[v0.5.3](https://github.com/jonasblixt/ufsm/tree/v0.5.3) tag: `tests/`, `examples/`, `doc/transition_demo.ufsm` and
the old editor's own `compose/src/canvas.ufsm`. They are the input of the v0 reader and the migrator's tests
(`packages/core/test/v0.test.ts`, `v1.test.ts`, `sheet.test.ts`).

The v1 files of the same name in `examples/` and `tests/models/` are the converter's output for these; a test keeps them
equal (except the few it lists as fixed by hand). Do not edit these files: they record what v0.5 wrote.
